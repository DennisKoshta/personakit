# Follow-up studies

Twelve small studies run after the [original study](../study/README.md) (2026-10-28), each asking one question the original left open. They are listed with their verdicts, including the ones that failed. Each folder holds the study's write-up (`README.md`), its preregistered design where there is one (`DESIGN.md`) and the scripts that produced the numbers. Terms and stage names (H3, H5, X3 and so on) are explained in the [glossary](../README.md#glossary).

**What is and isn't here**
- **No raw outputs.** Rates and summaries only: no generations, judge transcripts or per-reply files. The write-ups sometimes name such files (`texts.jsonl`, `results.json`, …) or paths on the private output volume; they aren't in this repository. The few sample replies quoted are benign persona lines.
- **The scripts need helpers that aren't included.** They import `hf_cache.py` (pinned Hugging Face downloads on a Modal volume), `evals.py` (MMLU scoring) and a CPU check runner from the private harness the studies ran in. Some read the stored outputs of earlier private runs, and they expect the study's helper modules (`persona.py`, `prompts.py`, `judge.py`, `jobs.py`) from [`../study/`](../study/). They are the code that produced the numbers, not a package to run. The kit at the root runs on its own.
- **Verdicts are the studies' own**, against decision rules written before the compute. The write-ups are long and dense; each starts with an answer summary.
- **Left out: `port-persistence`** (does a ported recipe keep its persona under a second-turn challenge, with matched-layer ports and deterministic atlases?). `multiturn-challenges` compares against its single-turn pilot, which is why that study cites it. It stopped at its budget cap with one of six concepts done (three sizes, `wizards` only), and its own report calls the full study incomplete.

## Reading order

Start with `h3-interaction-kl`, then `turn2-confession-circuit` and `multiturn-challenges` (persistence), then `negative-and-blend`. The rest are mostly negative or partial results that bound what the kit can claim.
